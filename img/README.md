# 図版（画像）の置き場所

歴史の「史料・資料の読み取り」には、画像を使う問題が8問（資料8点）あります。
このフォルダに、下の表のファイル名で画像を保存すると、その資料の問題が自動で出題されるようになります。
画像がないあいだは、その問題は出題されません（エラーにもなりません）。

画像の横幅は800px程度に縮小すると、ページが軽くなります。

## 利用条件（2026年10月に確認）

- **ColBase**：利用規約を守り、出典を明記すれば、申請不要・無料で、商用・非商用を問わず利用できます（政府標準利用規約に準拠し、CC BY と互換）。画像の加工もできます。
  - 参考：[文化庁「ぶんかる」ColBaseの紹介](https://www.bunka.go.jp/prmagazine/rensai/bunkazai/bunkazai_119.html)、[美術手帖（三の丸尚蔵館の収蔵品がColBaseで利用可能に）](https://bijutsutecho.com/magazine/news/headline/28052)
  - 利用前に、ColBaseの利用規約ページで最新の条件を確認してください。作品によっては、第三者の権利についての注意が書かれている場合があります。
- **国立国会図書館デジタルコレクション**：「インターネット公開（保護期間満了）」の資料は、申請不要で自由に利用できます。出典の記載をお願いしています。
  - 参考：[国立国会図書館「ウェブサイトからのコンテンツの転載」](https://www.ndl.go.jp/use/reproduction)

## 出典の表示

アプリでは、画像の下に「出典：ColBase（https://colbase.nich.go.jp/）」などを表示し、
作品名・所蔵先は答えの解説に表示します（作者名などが答えのヒントにならないようにするため）。
表示する文は `index.html` の資料データ（`img:{f, cr}` の `cr`）で変更できます。
作品ページのURLも表示したい場合は、`cr` に追加してください。
